# ADR-0003: v0.2 — one language, on-device translation, word-keyed cards

- Status: Accepted (2026-09-18)
- Spec: `.ai/specs/000-v0.2-revamp/`

## Context

The project had two backends (Fastify prototype, Spring Boot), a self-hosted LibreTranslate container, gamification and AI features, and about 24k lines of source (Java, TypeScript, SQL, CSS). It was hard to run, deploy and change. The goal is an app that is small, easy to maintain and cheap to host.

## Decisions

1. **NestJS + Prisma + Postgres** replaces Spring Boot and Fastify. All code is TypeScript and shares one package (`@vocab-os/shared`) with the web app and extension. Scope: auth, cards, review, sync, stats. Gamification (XP, badges) and server-side AI are dropped.
2. **On-device translation**, no translation server: Chrome's built-in Translator API first, then `Xenova/opus-mt-en-vi` via transformers.js (q8, WASM) in an offscreen document. LibreTranslate and the mock provider are removed.
3. **Card id = `targetLanguage:normalizedWord`**. Devices agree on identity without talking to each other, which removes client/server id mapping and duplicate merging.
4. **Last-write-wins sync on whole cards**, including review fields. The pull cursor uses the server clock (`syncedAt`). This replaces bootstrap, dry-run and backup flows and fixes the lost-review-progress bug.
5. **One scheduler, one stats function** in `shared`, used by all three apps.
6. **Single 30-day JWT**, no refresh tokens. This is simpler; the trade-off is that tokens cannot be revoked early.
7. **Pinned majors:** NestJS 11, Prisma 6, transformers.js 3, TypeScript 5.9, Vite 6, Vitest 3, Zod 3, Tailwind 3. Newer majors existed (NestJS 12, Prisma 7/8, transformers.js 4, TS 7) but were not verified for this setup. Upgrading is a spec of its own.
8. **API runs as CommonJS** (Nest default) and loads the ESM `shared` package through Node's `require(esm)`, so it needs Node ≥ 22.12.

## Consequences

- One `pnpm dev` runs everything; deploying the API is `pnpm build` + `prisma migrate deploy` + `node dist/main.js` on any Node host with Postgres.
- The extension package is about 22 MB unpacked (ONNX Runtime WASM). The offline model downloads once on first use (~100 MB).
- Offline translation quality for single words is weaker than for sentences (known limitation of opus-mt).
- Stats (streak, today counts) are derived from `createdAt`/`lastReviewedAt` only; there is no review history table. This is simple but approximate. A review log is a possible future spec.
